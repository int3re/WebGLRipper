Extract 3D models from any website

WebGL Ripper is a free browser extension that captures the 3D models and textures a WebGL page draws and saves them as GLB (glTF 2.0) or OBJ — ready for Blender, Unity, Unreal or Godot.

Download for Chrome & Firefox Source on GitHub

Version 1.1.2 · MIT license · Chrome, Edge, Brave, Opera 121+ · Firefox 128+

What it does

GLB or OBJ

One .glb with embedded textures and PBR materials, or OBJ + MTL + PNG in a ZIP — or both.

Preview before download

Turn the captured scene around in the page and choose the meshes you want.

Pick by clicking

Shift+Insert, click an object, and only that object is saved — even through post-processing.

Ready to import

Meshes in place, centered on the floor, welded, with normals and material colors.

Clean output

Shadow passes, depth passes, axis gizmos and post-processing quads are left out.

Exact textures

Real size, byte for byte, including compressed, float and transparent textures.

Works with your engine

three.js, Babylon.js, PlayCanvas, Unity WebGL, Godot, Emscripten, plain WebGL 1 and 2.

Private and light

No network requests. No cost per draw call until you press the hotkey.

Rip just one object

Install and use

  1. Download webglripper-…-chrome.zip or …-firefox.zip from the latest release.
  2. Chrome / Edge / Brave / Opera: unzip, open chrome://extensions, enable Developer mode, click Load unpacked and pick the folder. Firefox: about:debugging#/runtime/this-firefox → Load Temporary Add-on… → the zip.
  3. Open a page with a 3D model and press Insert. Choose meshes in the preview and press Download.
  4. Import the file in Blender: File → Import → glTF 2.0 or Wavefront (.obj).

WebGL Ripper is not on the Chrome Web Store or any other store; copies found there are not from this project.

Questions

How do I download a 3D model from a website?

Install WebGL Ripper, open the page, wait until the model is visible and press Insert. A 3D preview opens in the page; choose the meshes and press Download to get a GLB or OBJ file.

Which sites does it work on?

Any page that draws with WebGL: three.js, Babylon.js and PlayCanvas viewers, Unity WebGL and Godot games, product configurators, 3D galleries. Not pages that stream server-rendered video, or draw from a Web Worker.

Why is a character in a T-pose?

Characters animated on the GPU are saved in their bind pose: the vertex shader moves the vertices, and the extension saves the data the page uploaded.

How does it work?

It runs inside the page before the page's own scripts, records the draw calls of one frame — geometry, textures and matrices — cleans them up and writes GLB or OBJ. The full description.

Does it send my data anywhere?

No. The extension makes no network requests at all.

Is ripping allowed?

Models and textures belong to their authors. Rip only what you may use — your own work, freely licensed assets or content you have permission for — and respect each site's terms.
